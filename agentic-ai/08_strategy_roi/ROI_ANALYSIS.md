# ROI Analysis: Agentic vs Classique

**Résultat global : 3810.50€ éconimisés sur 4800€ (-79%), pour un temps humain passant de 88h à 17h (-81%).**

| Tâche | Coût Classique | Coût Agentic | Économie |
|---|---:|---:|---:|
| Module Authentification | 1 600,00 € | 202,50 € | 1 397,50 € |
| Script de Migration BDD | 800,00 € | 162,00 € | 638,00 € |
| Refactoring Legacy Code | 2 400,00 € | 625,00 € | 1 775,00 € |

**Constats clés :**

Sur les trois cas d'usage évalués (Module d'Authentification, Script de Migration BDD, et Refactoring de code legacy), le coût total de réalisation bascule d'une méthode classique de 4800€ à seulement 989.50€ sous l'approche Agentic, générant ainsi une économie globale cumulée de 3810.50€.
Le retour sur investissement est particulièrement frappant sur le refactoring et le module d'authentification, où les gains de temps (réduction drastique des heures manuelles) absorbent largement les coûts marginaux des tokens.
